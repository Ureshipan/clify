# CLIFY

Ранний настольный Rust-клиент Navidrome с графическим интерфейсом в стиле терминала и интеграцией AudioMuse-AI. Android пока не реализован.

## Возможности

- Вход в Navidrome по Subsonic API, поиск и случайная подборка треков, просмотр исполнителей и альбомов, избранное, оценки и обложки.
- Просмотр, создание и редактирование плейлистов на сервере. Выбранный трек можно добавить в любой плейлист; из открытого плейлиста можно удалить отдельные треки.
- Микс по треку через Navidrome, а также «волна из избранного»: ограниченная подборка по нескольким случайным избранным трекам и их похожим композициям. Это простой алгоритм на основе избранного, а не самообучающаяся радиостанция. Обоим режимам нужен источник похожих треков на сервере, например плагин AudioMuse-AI.
- Прямое подключение к AudioMuse-AI: миксы по треку с настройками, настроению и исполнителю через Song Alchemy. Подключение к AudioMuse-AI не требует плагина Navidrome, но медиатека должна быть проанализирована и сопоставлена с тем же сервером Navidrome.
- Волна по жанру, настроению или треку заранее запрашивает следующие подборки и не повторяет недавно звучавшие композиции, пока есть другие варианты. Для жанра используются метаданные Navidrome; настроение берётся из AudioMuse-AI, для трека можно выбрать Navidrome или AudioMuse-AI. На маленькой медиатеке повторы возможны; если сервер не возвращает подходящих треков, волна остановится. История волны ограничена последними 200 треками.
- Очередь с изменением порядка, удалением, перемешиванием оставшихся треков и повтором трека или списка. Очередь можно вручную сохранить на сервер и восстановить на другом клиенте; стандарт Subsonic неоднозначно обрабатывает несколько вхождений одного ID. Пауза, перемотка, громкость и восстановление позиции требуют `mpv`; запасной `ffplay` воспроизводит с начала.
- ReplayGain для mpv можно выключить или применять по треку/альбому; настройка действует со следующего трека и требует соответствующих тегов в переданном сервером аудиофайле.
- Тексты из OpenSubsonic: доступные языки, подсветка синхронизированной строки и переход по ней через `mpv`. Таймер сна останавливает воспроизведение через 15, 30 или 60 минут либо в конце трека.
- Отображение текущего воспроизведения в Navidrome и scrobbling после половины трека или четырёх минут прослушивания (что наступит раньше). Подтверждение прослушивания работает через `mpv` и учитывает наблюдаемое продвижение позиции; для `ffplay` оно не отправляется.
- На Linux приложение публикует MPRIS-интерфейс для системных кнопок и показывает обложку из локального кэша. Пауза, перемотка и изменение громкости через MPRIS требуют `mpv`.
- Треки и обложки, метаданные треков, жанров и плейлистов кэшируются отдельно для каждого сервера и пользователя. Следующие два трека очереди загружаются заранее; функцию можно отключить в настройках. Для одинаковых параллельных запросов в одном процессе используется одна загрузка. Плейлисты и метаданные используются из кэша до пяти минут и обновляются после изменений; для списков есть кнопка принудительного обновления.
- Аудиокэш по умолчанию ограничен 2 ГиБ на аккаунт; лимит от 1 до 20 ГиБ и текущий размер доступны в настройках. Старые треки вытесняются первыми. Проигрываемый и предзагруженные треки защищены от удаления, поэтому занятое место может временно превышать лимит. Обложки и метаданные в этот лимит не входят. Кэш можно очистить в настройках при остановленном плеере.
- Загрузка отменяется при смене очереди, а при временном сбое сервера повторяется до двух раз. Отмена ожидающего сетевого чтения происходит после его завершения или тайм-аута.
- Четыре палитры; выбранная палитра и громкость сохраняются между запусками.

Дважды нажмите на трек для воспроизведения или выберите его и нажмите **PLAY**. В очереди сохраняется список, из которого запущен трек. Сохранение нового плейлиста использует текущий список в приложении: результат поиска, микс, случайную подборку или открытый плейлист.

## Запуск

Установите Rust/Cargo и `mpv`, доступный в `PATH`. Как запасной вариант подходит FFmpeg с `ffplay`. На Linux также нужны графическое окружение и зависимости для сборки приложений X11/Wayland. На Windows используйте Rust MSVC и добавьте каталог с `mpv.exe` или `ffplay.exe` в `PATH`.

```sh
cargo run
```

### Сборка

Скрипты создают release-версию с зафиксированными зависимостями из `Cargo.lock`:

- Linux: `./scripts/build-linux.sh` → `target/release/clify`. Нужны Rust и библиотеки разработки X11, Wayland и OpenGL (например, на Ubuntu: `libx11-dev libxkbcommon-dev libwayland-dev libgl1-mesa-dev`).
- Windows: `powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1` → `target/release/clify.exe`. Запускайте на Windows с установленными Rust MSVC и Visual Studio Build Tools (C++).
- Android: `./scripts/build-android.sh` пока завершится с ошибкой: Android-приложение ещё не реализовано. После добавления проекта `android/gradlew` скрипт запускает `assembleRelease`; для подписанного APK потребуются Android SDK и настройка подписи проекта.

Для воспроизведения рядом с приложением или в `PATH` также нужен `mpv` либо `ffplay`; скрипты не включают проигрыватель в сборку. При заданном `CARGO_TARGET_DIR` Cargo помещает настольные бинарные файлы в указанный каталог.

Укажите адрес Navidrome, включая путь установки при необходимости, логин и пароль. Пароли и токены сохраняются только в памяти и запрашиваются снова после перезапуска. Используйте HTTPS за пределами доверенной сети: Subsonic-токен передаётся серверу, первое воспроизведение загружает весь трек в кэш перед запуском; адрес с токеном не передаётся внешнему проигрывателю.

### AudioMuse-AI

После входа в Navidrome откройте **Настройки → AudioMuse-AI** и укажите URL сервиса. Можно войти под отдельной учётной записью AudioMuse-AI, передать API-токен или выбрать подключение без авторизации, если она отключена на сервере. API-токен AudioMuse-AI предоставляет административный доступ к сервису. Если AudioMuse-AI подключён к нескольким медиасерверам, укажите имя или идентификатор сервера Navidrome; иначе используется сервер AudioMuse-AI по умолчанию. На странице **Миксы** выберите нужный режим. Для режима по треку сначала выберите трек в медиатеке.

Доступные настроения и их варианты берутся из AudioMuse-AI; их набор зависит от версии и данных сервера. Для создания плейлиста откройте страницу **Плейлисты**, введите имя и сохраните текущий результат.

## Ограничения

- Android, фоновое воспроизведение, управление в шторке и виджет ещё не реализованы. Нужны Android-проект, мобильный аудиодвижок и медиасервис.
- Реальные серверы Navidrome и AudioMuse-AI, графический интерфейс, реальное воспроизведение через `mpv` и `ffplay`, а также Windows в текущем окружении не проверены. API и канал управления `mpv` проверяются с локальными имитациями серверов.
- Плеер использует внешнюю программу; `ffplay` не поддерживает паузу, перемотку, изменение громкости во время воспроизведения и подтверждение прослушивания в CLIFY. Переход между треками не является бесшовным.
- Долговременное безопасное хранение учётных данных и полноценный автономный вход ещё не реализованы. Уже загруженный трек можно повторно воспроизвести из кэша во время текущего сеанса; для нового входа требуется сервер. Ограничение размера применяется к аудио; обложки и метаданные ограничиваются только ручной очисткой. Блокировки загрузок и защита файлов согласуются между клиентами внутри одного процесса, но не между несколькими запущенными копиями приложения.
